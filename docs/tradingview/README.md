# TradingView 三均线策略（MA5/50/120）

本目录提供一份可在 TradingView 使用的 Pine Script v5 策略源码，基于 5/50/120 日均线（可在任意周期下使用）。

文件：ma5-50-120-strategy.pine

主要特性：
- 支持均线类型选择：SMA/EMA/WMA/RMA
- 入场逻辑可选：
  - Cross + Trend：快线与中线金叉，且中线在慢线上方
  - Alignment + Price > Fast：多头排列（MA5>MA50>MA120）且收盘上破快线
  - Cross Only：仅依据快中线金叉/死叉
- 做多/做空双向策略，可单独关闭做空
- 风险控制：ATR 或 百分比 止盈/止损
- 可选移动止损（ATR 或 百分比）
- 回测时间过滤
- 绘制三条均线并标注信号点位，内置警报条件

使用步骤：
1. 打开 TradingView，创建新策略脚本。
2. 复制 ma5-50-120-strategy.pine 的全部内容粘贴进去。
3. 点击添加到图表，按需调整参数后开始回测。

注意事项：
- 脚本仅作学习与回测示例，不构成投资建议，请自行承担交易风险。
- 该策略默认允许做空，如不需要请在参数中关闭“允许做空”。
- 若选择“移动止损”，TradingView 的限制下不可同时设置固定止盈/止损。
